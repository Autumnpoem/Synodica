# Kimi 编程月度会员接入

你购买的是 Kimi 编程套餐时，选择项目中的 **Kimi Code 官方套餐**。不要把其 Key 填进 Moonshot 开放平台：两者的凭据和用量来源不同。

## 创建编程套餐 Key

1. 打开 [Kimi Code 中国区控制台](https://www.kimi.com/code/console)，登录购买编程会员的账号。
2. 确认账号具有编程套餐权益，在控制台创建用于第三方工具的 API Key。
3. Key 只填入项目的服务商密码输入框，不发到聊天或截图里。

官方工具支持浏览器账号登录；本项目当前 Kimi 接口使用的是第三方工具 Key 方式，尚未接入 Kimi CLI 的 OAuth 登录导入。[Kimi Code 官方接入说明](https://www.kimi.com/code/docs/en/kimi-code/models.html)

## 填入项目

打开“设置 → 服务商”，找到 Kimi Code 官方套餐。如果该版本尚未提供现成条目，使用“添加 API 服务商”填写：

| 字段 | 中国区内容 |
|---|---|
| 类型 | OpenAI 兼容 API |
| 服务商 ID | kimi-code |
| 显示名称 | Kimi Code 官方套餐 |
| Base URL | https://api.kimi.com/coding/v1 |
| API Key | 刚创建的 Kimi Code Key |
| 模型 | 以官方控制台、模型列表和你的套餐权限为准 |

国际区的官方地址为 `https://api.kimi.ai/coding/v1`，应使用对应区域的账号和 Key。不要在中国区查询失败后自动把同一 Key 发送到国际区。[区域与模型配置](https://www.kimi.com/code/docs/en/kimi-code/models.html)

保存后，在成员资料中选择这个服务商，并填写正确模型 ID。现有模型名不会因为新增服务商而自动更新。部分模型有思考模式要求，应按官方模型页配置，不要通过随意改名来绕过权限或报错。

## 查询编程额度

打开“用量与额度”，刷新 Kimi Code 卡片。查询与实际编程调用共用该账号对应的套餐身份；多个成员使用同一账号时，不会各有一份独立额度。

页面按接口实际返回值展示五小时、周、月度总量、月度编程等窗口。按月付费是购买周期，不代表接口一定返回独立的月额度百分比；缺失窗口不会当作零使用量。

## 遇到问题

- 401 或 404：优先检查 Key 是否来自 Kimi Code，而不是 Moonshot 开放平台，以及区域是否正确。
- 403：检查该会员能否访问所选模型。
- 400：检查模型名称、思考模式及请求参数。
- 只看见“未登录或无密钥”：条目已建立，但尚未保存有效 Key。

普通 Kimi 网页会员、Kimi Code 和开放平台的 Key／余额不要混用。购买的具体权益以该账号控制台显示为准。


## 在当前星议界面中的具体路径

1. 在浏览器登录 [Kimi Code 控制台](https://www.kimi.com/code/console)，使用购买编程会员的账号。
2. 创建 Kimi Code 接口密钥，复制一次。
3. 回到“设置 → 服务商”，找到“Kimi Code（中国订阅）”或对应海外区条目，点击“配置”。
4. 粘贴密钥并保存，为角色选择该服务商与账号可用的模型。不要粘贴到聊天框。

如果你问的是 Kimi 官方工具本身：运行 `kimi` 后输入 `/login`，选择 Kimi Code（OAuth），在浏览器完成验证码授权。这个登录流程属于 Kimi 官方工具；星议当前使用 Code 密钥方式，不自动导入其 OAuth 文件。
