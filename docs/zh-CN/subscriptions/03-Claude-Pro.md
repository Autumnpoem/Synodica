# Claude Pro 接入

当前项目的 Claude 适配器复用 Claude Code 的登录。购买 Claude Pro 后，应以 Claude 账号完成官方登录；Anthropic Console API Key 是另一种计费身份。

## 登录步骤

确认已有官方 Claude Code：

```sh
claude --version
```

没有安装时按 [Claude Code 官方安装说明](https://code.claude.com/docs/en/setup)安装。然后在运行项目的同一个系统用户下执行：

```sh
claude
```

首次运行按提示登录 Claude 账号，选择你的 Pro 订阅所属账号。如果需要进入登录流程，在交互界面输入 `/login`。授权完成后回到终端，确认账号正确，再正常退出。[Claude Code 官方认证说明](https://code.claude.com/docs/en/authentication)

## 项目配置

打开“设置 → 服务商”，选择 Claude 订阅，API Key 留空。在成员资料中选择 Claude 服务商及可用模型。已有 API Key 或自定义服务地址时，先确认这是你想要的调用方式，不要直接覆盖其他人的配置。

服务商检查通过后，如需确认实际回答，可以给该成员发一句简短消息；这会使用订阅额度。当前自动测试使用模拟服务商，不等同于你的真实账号已完成联调。

## 额度读取需要单独同意

打开“用量与额度”，在设置区域按需要开启“读取 Claude Code 登录以查询用量”，然后刷新 Claude 卡片。

当前读取器只支持官方工具保存的登录文件；它不会读取 macOS 钥匙串，不会代你刷新 OAuth 凭证，也不会改动官方工具的登录状态。若 Mac 上的 Claude 登录保存在钥匙串中，可能出现“Claude 可正常调用，但项目无法读取额度”的情况。此时不要导出钥匙串、把令牌贴到项目聊天，或把 Pro 登录令牌填进 API Key 输入框。

关闭这项同意会中止相应查询，丢弃其迟到结果，并清除该账户的额度缓存。

## Ubuntu 与故障排查

在运行后端的用户下完成官方 Claude Code 登录。若授权需要浏览器，按官方工具显示的地址或步骤完成；不要把整个本机 `.claude` 文件夹覆盖到服务器。

- 登录成功但项目不识别：核对运行用户、HOME 和官方工具配置目录。
- 模型不可用：核对套餐权限和成员模型名，登录成功不等于有所有模型权限。
- 额度提示登录已过期：回官方工具更新登录，再刷新卡片。项目额度读取器不会替你轮换登录凭证。
- 只改用量同意开关不会把成员从 Pro 切换到付费 API。
