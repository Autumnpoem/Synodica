<h1 align="center">星议 · Synodica</h1>

<p align="center"><strong>让多个 AI 队友在同一工作空间里讨论、规划、实现和评审。</strong></p>

<p align="center"><a href="README.md">English</a> · <a href="docs/zh-CN/快速开始.md">快速开始</a> · <a href="docs/zh-CN/subscriptions/README.md">服务商与订阅配置</a></p>

星议把多个模型服务商与可复用的 AI 角色放进同一个工作空间。每个角色可以使用自己的服务商、模型和工作方式；角色可以在私聊、群聊或项目中协作。目标是让问题到评审结果的过程有迹可循，并由你决定后续行动。

## 几步开始

1. 从[发布页](https://github.com/Autumnpoem/Synodica/releases)下载适合你电脑的桌面包，或按[快速开始](docs/zh-CN/快速开始.md)从源码运行。
2. 打开 **设置 → 服务商**，配置要使用的账号或 API Key。订阅登录由运行后端的官方 CLI 使用；网页登录不会自动变成 API 权限。
3. 打开 **设置 → 团队 → 默认团队**，选择一个起始模板，检查并调整服务商、模型默认值后保存。
4. 先与一个角色私聊；需要多角色协作时，再创建群聊或项目。

| 模板 | 适合的起点 | 可调整内容 |
|---|---|---|
| **公司团队** | 产品规划、实现、交付与评审 | 新角色的服务商和模型默认值；已保存角色可在资料中编辑 |
| **学术／实验室团队** | 研究规划、证据分析、可复现工作与同行评审 | 新角色的服务商和模型默认值；已保存角色可在资料中编辑 |

两套模板各含五个可复用角色。再次应用模板时会复用已保存角色，不覆盖名字、人设或模型选择。本文不指定模型 ID；请按自己账号实际可用的模型配置。

## 协作方式

- **私聊：** 与一个选定角色单独交流。
- **群聊：** 单个 `@名字` 和私聊在本轮中只由被点名角色回复。使用 `@everyone` 或明确邀请全组的请求（例如“请所有人都发表意见”）可邀请未静音成员，最多 12 人。普通调度会选择 1–3 名相关角色。
- **项目：** 描述目标、选择参与角色，然后通过项目看板进行规划、质疑、任务分工、独立评审和证据记录。
- **开放式规划讨论：** 在计划评审者和决策负责人做决定前，符合条件的项目成员可各自进行一轮只读讨论，提出有依据的反对意见。默认最多邀请 6 人，可设为 1–12 人。负责人必须逐条记录处理结果和理由；跳过回复不代表同意。
- **停止并纠正：** 中断正在进行的工作并补充要求。小幅修改可继续执行；范围变化会等待你选择恢复或重新规划。停止讨论后恢复时只重新询问尚未回复的成员；纠正会使旧版本结果失效。
- **选择使用界面：** 可用桌面应用或浏览器访问。同一 Mac／Windows 客户端与手机浏览器连接到 Ubuntu 上同一台 HTTPS 服务器，并使用该办公室令牌登录后，可共享一个办公室。
- **切换语言：** 在应用中选择 English 或简体中文。

### 讨论设置与边界

在 **设置 → 通用 → 规划讨论** 中选择 **自动**、**开启** 或 **关闭**，并设置参与人数上限。**自动**模式会在项目包含公司或实验室内置角色时启用讨论；只有自定义角色的项目保持原流程。**开启**和**关闭**会明确覆盖自动设置。

静音成员、负责人和指定评审者不会成为讨论参与者。无法保证只读的配置也会从本轮规划讨论中略过。例如，带可写工具的 Gemini CLI 角色仍可用于普通聊天和实现，但不会被自动修改工具设置来参加只读讨论。个别参与者失败不会中断其他成员的发言。每个被请求的讨论轮次（包括跳过）都会使用一次模型调用，可能消耗服务商用量。

讨论结束后，由评审者检查计划，再由负责人作决定。每条反对意见会保留原始主张和理由，并记录“采纳、驳回、未解决、需要用户决定”及对应理由。未解决的意见会继续保留在项目上下文中。若意见需要你决定，请先填写理由并逐条处理，再明确点击 **开始**；项目会等待你的决定。

## 安装与指南

[快速开始](docs/zh-CN/快速开始.md)介绍 `Synodica-0.5.1-mac-arm64.dmg`、`Synodica-0.5.1-win-x64.zip`、源码安装命令、账号配置、手机访问和常见问题。桌面包尚未签名；macOS 包未经公证，Windows 真机测试仍待完成。请勿为安装而关闭操作系统安全保护。

- [服务商与订阅接入](docs/zh-CN/subscriptions/README.md)

浏览器界面可在 Node.js 22 或更新版本上本地运行，所需命令见[源码快速开始](docs/zh-CN/快速开始.md)。如需多人共用办公室，可在 Ubuntu 上通过 HTTPS 部署后端，让桌面端和手机连接同一服务。彼此独立的本地办公室不会自动合并。

## 当前版本与已知限制

当前文档面向 **0.5.1**。用量界面只展示服务商实际提供的数据，不会猜测缺失的额度。已知限制包括：Gemini Google 订阅暂无实时额度报告；dsh-pet 独立聊天服务尚未接入；桌面安装包未签名；Windows 尚未真机验收。
